# print-premise-receipt

你的方案看起来都对，但你不知道它悄悄假设了什么。这个 Skill 让 Agent 在给出方案之前，先打印一张前提小票——逐条列出结论依赖的事实性假设，并标注每条不成立时哪一部分作废。

## 安装

把 `SKILL.md` 复制到你所用 Agent 的 skills 目录，或直接把本仓库 clone 到本地 skills 路径下。本 Skill 遵循 agentskills.io 开放标准，同一份 SKILL.md 可被 Claude Code、Cursor、Codex、Copilot 等读取。

## 输出样例

```
前提小票
1. 慢在数据库而非网络 ｜ 若不成立：§1 §2 全部作废
2. orders 表 < 5000 万行 ｜ 若不成立：§2 的建索引方式作废，需改分区表
3. 读请求占 90% 以上 ｜ 若不成立：§3 缓存收益归零，整节作废
4. 允许 5 分钟以内锁表 ｜ 若不成立：§2 需改为在线 DDL
5. ⚠ 未确认：orders 是否有 tenant_id ｜ 若有：§2 联合索引列顺序反转 ｜ 确认方式：\d orders
```

左边那份让人直接排期，右边这份让人先去敲一条 `\d orders`。

## 触发条件与边界

**触发**：用户明确要拿输出去评审、上线、排期或决策；输出依赖无法当下验证的环境事实；你写出了"假设…""一般来说…"这类没有落实的判断。

**不触发**：纯事实查询；输出不超过 300 字且只涉及一个决定；一句追问就能确定的前置信息——直接问，不写小票。

**边界**：不评价方案好坏，不列偏好性假设，不替代提问，不跨会话继承前提。
